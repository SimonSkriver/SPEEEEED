# Performance
On this page, we discuss **performance guidelines** and present three **benchmarks** where **Spline Architect** 
is compared against other popular spline tools.

**Benchmarks:**
1. [Runtime deformation](#benchmark-1-runtime-deformation)
2. [Move 20000 objects](#benchmark-2-move-20000-objects)
3. [Create 1000 Splines](#benchmark-3-create-1000-splines)

This page is mainly relevant for those who want to use splines in their **built game**. 
If you only use Spline Architect as a **level design** or **dressing** tool and have the **Component** 
option on both the **Spline** and **SplineObject** to **"Remove from build"**, 
all runtime systems related to **Spline Architect** will be removed from the final build. 
In that case, **Spline Architect has zero performance impact** on your game, aside from the **meshes generated by it**.

## Performance guidelines
By default, **Spline Architect** is designed to be very performant, but it also provides many options for further optimization.

We will start with the settings that provide the **largest performance improvements**, 
and then work our way down to smaller optimizations that are still useful to know.

### GPU Instancing <span style="color:#E317FF">(Up to 1250% Faster)</span>
This feature is only accessible through the Spline Architect API. **SplineInstances** cannot be created like regular **SplineObjects** while working in the Unity Editor.

Instead of using **SplineObjects**, which are regular Unity components attached to a **GameObject**, you can use **SplineInstances**. 
A **SplineInstance** is not a component and is instead managed by Spline Architect's internal GPU instancing system. 
Due to the nature of GPU instancing, meshes cannot be deformed using **SplineInstances**. Instead, they should be viewed as extremely performant spline followers.

To get the absolute best performance from **SplineInstances**, your material should use a shader that supports **assumeuniformscaling**. 
This increases the GPU instance batch size from **512** to **1024**, improving rendering performance. However, when using **assumeuniformscaling**, all axes must use the same scale value. 
Spline Architect comes with a shader that supports **assumeuniformscaling**, located in the **Examples** folder.

**Start and End Scheduling**, **Job Interval**, and **Initial Delay** are not supported for **SplineInstances** because their internal system is highly optimized, 
and supporting these features would reduce performance. However, **Frame Spreading** is fully supported and can significantly improve performance when used.

### Deformation Scheduling <span style="color:#FE4E37">(Up to 250% Faster)</span>
You can find the **Deformation Scheduling** section in the spline menu. It contains various settings that are explained below.

#### Start and End scheduling
A simple performance improvement is setting **Start** to **Update** and **End** to **Late Update**. 
This starts all deformation jobs during the Update loop and allows them to run until Late Update. 
If you have a lot of code running between these loops, this can noticeably improve performance.

#### Job interval
This determines how many frames pass before a deformation job runs again. 
For example, increasing the **Job interval** from **0 to 2** can often double performance. 
However, higher values mean deformations will not update every frame, which may appear slightly laggy if set too high.   

The **Job interval** affects all spline objects but provides the greatest performance improvement when deforming large meshes. 
For followers and many smaller mesh deformations, **Frame Spreading** usually provides better performance improvements.   

You can also adjust this value at **runtime** through scripts. This is useful for background animations far away from the player. 
When the player is far away, increase the **Job interval**. When the player is close, reduce it to a low value or **0**.

#### Initial Delay
There is also an **Initial Delay** option. 
For example, if two splines both have an **Job interval** of **1**, they will normally complete their deformation jobs on the same frame. 
Since applying transforms has some overhead, you can improve performance by finishing them on different frames. 
This can be done by setting **Initial Delay** to **1** on one spline and **0** on the other.

#### Frame spreading
This feature applies to all **SplineObjects** animated on a spline. 
It spreads the update work across multiple frames instead of updating all objects in the same frame, which can significantly reduce per-frame CPU cost.

However, higher values mean each **SplineObject** updates less frequently, and very high values can make animations appear laggy.
This feature is mostly intended for followers but can also be used for **deformations**, as long as they do not need to stay aligned with each other. 
If they must stay aligned, you should only use the **Job interval** setting.

Like the **Job interval** setting, this value can also be changed at runtime. 
This is useful for optimizing animations that are farther away from the player.

Frame spreading does not work with the **Spline Population** system.

### Static segments <span style="color:#FF874A">(Up to 50% Faster)</span>
Each segment can be set to **Static** either in the UI in the editor or by using scripts.
Setting a segment to **Static** will skip the cached normal calculations for that segment and use the spline transform's up direction as the origin for the normals.
This can greatly improve **performance** if you use very long splines with many control points/segments. However, static segments will not work well with **loops** or similar shapes.

### Skip tangents <span style="color:#FFB34A">(Up to 15% Faster)</span>
You can enable **Skip Tangents** on deformations. 
If your shaders or lighting effects do not require tangents, disabling them can improve **performance by around 7.5% to 15%**.

This setting is directly related to the **normal type** you use. 
**Spline Based (Default)** and **Cylinder Based** normals are by far the most performant options.

If you use **Unity Calculated** normals, enabling **Skip Tangents** can improve performance by **100% to 200%**. 
However, Unity calculated normals are still significantly slower than **Spline Based** or **Cylinder Based** normals, 
so those remain the recommended choice even when skipping tangents.

### Set spline.jobUpdateMode to always update <span style="color:#FFB34A">(Up to 15% Faster)</span>
spline.jobUpdateMode determines if SplineObjects should always be processed or only processed when changes are detected.
When set to Always Update, the normal dirty-check logic is bypassed and spline objects are processed every update cycle.
This can improve performance when many spline objects are known to update together every frame. In such cases, performance can improve by around 15%.
This setting can currently only be set through script on the spline (spline.jobUpdateMode).

### Spline and Normal Resolution <span style="color:#FEE237">(Up to 5% Faster)</span>
In the spline menu you will find two options called **Spline Resolution** and **Normal Resolution**.

The default values for these settings can be a bit high for **shorter splines**, especially those **25 meters or less with few control points**. 
Reducing the resolution by a factor of **2 to 5** can slightly improve **performance** and also reduce **memory usage**.

## Benchmarks
Test settings, package versions, hardware information, and test scripts are included below to make the results as transparent and reproducible as possible. 
Results may vary depending on hardware, Unity version, package version, and project setup. 

To be included in these benchmarks, a tool must meet the following requirements:
- Can deform meshes along splines at runtime.
- Can move objects along splines at runtime.
- Can create and modify splines at runtime.
- Uses distance-based spline sampling to prevent stretching or squeezing during deformation.

One custom test mesh with 26,313 vertices was deformed. One **knot** was continuously moved during the test using the script below, 
with all rebuild triggers removed from the **SplineCurveMesher** component.

```csharp
using UnityEngine;
using UnityEngine.Splines;
using sc.splinemesher.pro.runtime;

public class MoveKnot : MonoBehaviour
{
    public int knotIndex = 0;
    public float height = 2f;
    public float duration = 1f;

    private SplineContainer splineContainer;
    private BezierKnot originalKnot;
    private Vector3 originalPosition;
    private SplineCurveMesher splineCurveMesher;
    private Spline spline;

    private float timer = 0f;

    void Start()
    {
        splineCurveMesher = GetComponent<SplineCurveMesher>();
        splineContainer = GetComponent<SplineContainer>();
        originalKnot = splineContainer.Spline[knotIndex];
        originalPosition = originalKnot.Position;
        spline = splineContainer.Splines[0];
    }

    void Update()
    {
        timer += Time.deltaTime;
        float time = timer / duration;

        float currentHeight = Mathf.Lerp(0f, height, time);

        Vector3 newPosition = originalPosition + new Vector3(0, currentHeight, 0);
        BezierKnot currentKnot = splineContainer.Spline[knotIndex];
        currentKnot.Position = newPosition;
        splineContainer.Spline.SetKnot(knotIndex, currentKnot);

        if (timer >= duration)
            timer = 0f;

        splineCurveMesher.UpdateCachedSpline(spline);
        splineCurveMesher.Rebuild();
    }
}
```

```csharp
using System.Collections.Generic;

using UnityEngine;
using Unity.Jobs;
using Unity.Burst;
using Unity.Collections;
using Unity.Mathematics;
using Random = UnityEngine.Random;

using SplineArchitect;

public class MoveInstancesSplineArchitect : MonoBehaviour
{
    [BurstCompile]
    private struct SetPositionJob : IJobParallelFor
    {
        public NativeArray<NativeSplineInstance> nativeSplineInstances;
        [ReadOnly] public float deltaTime;
        [ReadOnly] public float speed;
        [ReadOnly] public float splineLength;

        public void Execute(int i)
        {
            NativeSplineInstance nsi = nativeSplineInstances[i];
            float3 prevPos = nsi.SplinePosition;

            nsi.SplinePosition = new float3(nsi.SplinePosition.x, nsi.SplinePosition.y, nsi.SplinePosition.z + deltaTime * speed);

            if (nsi.SplinePosition.z > splineLength)
                nsi.SplinePosition = new float3(nsi.SplinePosition.x, nsi.SplinePosition.y, 0);

            nativeSplineInstances[i] = nsi;
        }
    }

    public Mesh mesh;
    public Material material;
    public int amount;
    public float offsetXY = 2;
    public float speed;

    private Spline spline;

    void Start()
    {
        spline = GetComponent<Spline>();
        spline.InstancingReceiveShadows = true;
        spline.InstancingCastShadows = UnityEngine.Rendering.ShadowCastingMode.On;

        for (int i = 0; i < amount; i++)
        {   
            CreateInstance();
        }
    }

    void Update()
    {
        foreach (KeyValuePair<ulong, InstanceBatch> item in spline.GetInstanceBatchesUnsafe())
        {
            InstanceBatch batch = item.Value;

            // Set positions
            SetPositionJob setPositionJob = new SetPositionJob()
            {
                nativeSplineInstances = batch.NativeSplineInstances.AsArray(),
                speed = speed,
                deltaTime = Time.deltaTime,
                splineLength = spline.Length,
            };
            JobHandle jobHandle = setPositionJob.Schedule(batch.Count, 32);
            jobHandle.Complete();
        }
    }

    private void CreateInstance()
    {
        float3 startPos = new float3(Random.Range(-offsetXY, offsetXY), Random.Range(-offsetXY, offsetXY), Random.Range(0, spline.Length));
        spline.CreateSplineInstance(mesh, material, startPos, quaternion.identity, new Vector3(1, 1, 1));
    }
}
```

```csharp
public class MoveObjectsSplineArchitect : MonoBehaviour

    public float minOffsetXY = -5f;

    {
        for (int i = 0; i < followers.Count; i++)
        {
            SplineObject so = followers[i];
            so.localSplinePosition.z += speed * Time.deltaTime;

            if (so.localSplinePosition.z > spline.Length)
                so.localSplinePosition.z = 0;
        }
    }
}
```

```csharp
using System.Collections.Generic;
using UnityEngine;
using Dreamteck.Splines;

public class MoveObjectsDreamteck : MonoBehaviour
{
    public GameObject prefab;
    public int amount = 5000;
    public float minOffsetXY = -5f;
    public float maxOffsetXY = 5f;
    public float speed = 5f;

    private SplineComputer spline;
    private readonly List<Transform> instances = new List<Transform>();
    private readonly List<double> instanceTimes = new List<double>();
    private readonly List<Vector2> instanceOffsets = new List<Vector2>();

    private void Start()
    {
        spline = GetComponent<SplineComputer>();

        for (int i = 0; i < amount; i++)
        {
            float ranX = Random.Range(minOffsetXY, maxOffsetXY);
            float ranY = Random.Range(minOffsetXY, maxOffsetXY);
            double ranP = Random.Range(0f, 1f);

            GameObject instance = Instantiate(prefab);
            Transform instanceTransform = instance.transform;

            instances.Add(instanceTransform);
            instanceTimes.Add(ranP);
            instanceOffsets.Add(new Vector2(ranX, ranY));
        }
    }

    private void Update()
    {
        float step = speed * Time.deltaTime;

        for (int i = 0; i < instances.Count; i++)
        {
            double time = instanceTimes[i];
            time = spline.Travel(time, step);

            if (time > 0.999f) time = 0;
            instanceTimes[i] = time;

            SplineSample sample = spline.Evaluate(time);

            Vector3 position = sample.position;
            Vector3 forward = sample.forward.normalized;
            Vector3 up = sample.up.normalized;
            Vector3 right = Vector3.Cross(up, forward).normalized;

            Vector3 offset = instanceOffsets[i];
            Transform instance = instances[i];

            Vector3 finalPosition = position + right * offset.x + up * offset.y;

            instance.SetPositionAndRotation(finalPosition, Quaternion.LookRotation(forward, up));
        }
    }
}
```

```csharp
using System.Collections.Generic;
using UnityEngine;
using FluffyUnderware.Curvy;

public class MoveObjectsCurvySpline : MonoBehaviour
{
    public GameObject prefab;
    public int amount = 5000;
    public float minOffsetXY = -5f;
    public float maxOffsetXY = 5f;
    public float speed = 5f;

    private CurvySpline spline;
    private readonly List<Transform> instances = new List<Transform>();
    private readonly List<float> instanceDistances = new List<float>();
    private readonly List<Vector2> instanceOffsets = new List<Vector2>();

    private void Start()
    {
        spline = GetComponent<CurvySpline>();

        for (int i = 0; i < amount; i++)
        {
            float ranX = Random.Range(minOffsetXY, maxOffsetXY);
            float ranY = Random.Range(minOffsetXY, maxOffsetXY);
            float ranD = Random.Range(0f, spline.Length);

            GameObject instance = Instantiate(prefab);
            Transform instanceTransform = instance.transform;

            instances.Add(instanceTransform);
            instanceDistances.Add(ranD);
            instanceOffsets.Add(new Vector2(ranX, ranY));
        }
    }

    private void Update()
    {
        float delta = speed * Time.deltaTime;

        for (int i = 0; i < instances.Count; i++)
        {
            float distance = instanceDistances[i] + delta;
            if (distance > spline.Length) distance = 0;

            Transform instance = instances[i];
            Vector3 offset = instanceOffsets[i];

            instanceDistances[i] = distance;
            Vector3 position = spline.InterpolateByDistanceFast(distance, Space.World);
            Vector3 tangent = spline.GetTangentByDistanceFast(distance, Space.World).normalized;

            float tf = spline.DistanceToTF(distance);
            Vector3 up = spline.GetOrientationUpFast(tf, Space.World).normalized;
            Vector3 right = Vector3.Cross(up, tangent).normalized;
            Vector3 finalPosition = position + right * offset.x + up * offset.y;

            instance.SetPositionAndRotation(finalPosition, Quaternion.LookRotation(tangent, up));
        }
    }
}
```

```csharp
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.Splines;
using Unity.Mathematics;
using Random = UnityEngine.Random;

public class MoveObjectsUnitySpline : MonoBehaviour
{
    public GameObject prefab;
    public int amount = 5000;
    public float minOffsetXY = -5f;
    public float maxOffsetXY = 5f;
    public float speed = 5f;

    private SplineContainer splineContainer;
    private float splineLength;
    private readonly List<Transform> instances = new List<Transform>();
    private readonly List<float> instanceTimes = new List<float>();
    private readonly List<Vector2> instanceOffsets = new List<Vector2>();

    private void Start()
    {
        splineContainer = GetComponent<SplineContainer>();
        splineLength = splineContainer.Spline.GetLength();

        for (int i = 0; i < amount; i++)
        {
            float ranX = Random.Range(minOffsetXY, maxOffsetXY);
            float ranY = Random.Range(minOffsetXY, maxOffsetXY);
            float ranT = Random.Range(0f, 1f);

            GameObject instance = Instantiate(prefab);
            Transform instanceTransform = instance.transform;

            instances.Add(instanceTransform);
            instanceTimes.Add(ranT);
            instanceOffsets.Add(new Vector2(ranX, ranY));
        }
    }

    private void Update()
    {
        float delta = (speed / splineLength) * Time.deltaTime;

        for (int i = 0; i < instances.Count; i++)
        {
            float time = instanceTimes[i] + delta;
            if (time > 1) time = 0;
            instanceTimes[i] = time;

            Transform instance = instances[i];
            Vector3 offset = instanceOffsets[i];

            if (!splineContainer.Evaluate(time, out float3 splinePosition, out float3 splineTangent, out float3 splineUp))
                continue;

            Vector3 forward = ((Vector3)splineTangent).normalized;
            Vector3 up = ((Vector3)splineUp).normalized;
            Vector3 right = Vector3.Cross(up, forward).normalized;
            Vector3 finalPosition = (Vector3)splinePosition + right * offset.x + up * offset.y;

            instance.SetLocalPositionAndRotation(finalPosition, Quaternion.LookRotation(forward, up));
        }
    }
}
```

### Benchmark 3 (Create 1000 splines)
In this benchmark, we measure how long it takes to create 1000 splines within a single frame.
Each spline is 50 meters long and has 5 control points. All tools cache lookup maps for normals and positions along the spline.
The lookup map density is set to 30 per segment, resulting in a total resolution of 120 for all tools.

Dreamteck Splines does not appear to transport its normals along the spline. 
This requires less processing, but can make it more difficult to create loops and similar shapes. 
All other tested tools appear to transport their normals.

The tests were performed using standalone Windows builds with Development Build disabled, running in windowed mode at 1280×720.
Each tool was tested separately. The first run was used as a warm-up and discarded, and the median was calculated from the following 10 test runs.

Garbage allocation was measured the first time 1000 splines were created after launching the build in development mode with the profiler attached. 
All tools consistently produce the same amount of garbage when the scene is reloaded and another 1000 splines are created within the same build session. 
The only exception is Curvy Splines, which produces 14.4 MB of garbage on the first run and 8.2 MB on each run after that.

Spline Mesher PRO and Spline Mesher SD use Unity Splines for this functionality, so their results are the same as Unity Splines.

```csharp
using System.Collections;
using System.Diagnostics;

using UnityEngine;

using SplineArchitect;

public class SplineArchitectCreateSplines : MonoBehaviour
{
    [Header("Spawn")]
    public int splineCount = 1000;
    public float spawnDelay = 2;
    public float spacing = 5;

    [Header("Control Points")]
    public int minControlPoints = 5;
    public int maxControlPoints = 5;

    [Header("Spline Length")]
    public float minLength = 50;
    public float maxLength = 50;

    private string resultText = "Waiting...";
    private GUIStyle resultStyle;

    private IEnumerator Start()
    {
        yield return new WaitForSeconds(spawnDelay);
        CreateSplines();
    }

    private void CreateSplines()
    {
        Stopwatch stopwatch = Stopwatch.StartNew();

        for (int i = 0; i < splineCount; i++)
        {
            CreateSpline(i);
        }

        stopwatch.Stop();
        resultText = "Spline Architect\n" + "Created " + splineCount + " splines\n" + stopwatch.Elapsed.TotalMilliseconds.ToString("F3") + " ms";
    }
```

##### Unity Splines
In the script below, a new SplineContainer is created for each spline. 
It might seem more intuitive to create a single SplineContainer and add all 1000 splines to it instead. 
This was also tested, but resulted in a creation time of 3606 ms, compared to the 1418 ms shown in the result table.
<details>
<summary><span style="color:#FFB34A;">Show the script used</span></summary>

```csharp
using System.Collections;
using System.Collections.Generic;
using System.Diagnostics;

using Unity.Mathematics;
using Unity.VisualScripting;
using UnityEngine;
using UnityEngine.Splines;
using Random = UnityEngine.Random;

public class UnitySplinesCreateSplines : MonoBehaviour
{
    [Header("Spawn")]
    public int splineCount = 1000;
    public float spawnDelay = 2;
    public float spacing = 5;

    [Header("Control Points")]
    public int minControlPoints = 5;
    public int maxControlPoints = 5;

    [Header("Spline Length")]
    public float minLength = 50;
    public float maxLength = 50;

    [Header("Other")]
    public bool useOneSplineContainer;

    private readonly List<BezierKnot> knots = new List<BezierKnot>();
    private SplineContainer splineContainer;
    private string resultText = "Waiting...";
    private GUIStyle resultStyle;

    private IEnumerator Start()
    {
        if(useOneSplineContainer)
            splineContainer = transform.AddComponent<SplineContainer>();

        yield return new WaitForSeconds(spawnDelay);
        CreateSplines();
    }

    private void CreateSplines()
    {
        Stopwatch stopwatch = Stopwatch.StartNew();
        for (int i = 0; i < splineCount; i++)
        {
            CreateSpline(i);
        }
        stopwatch.Stop();
        resultText = "Unity Splines\n" + "Created " + splineCount + " splines\n" + stopwatch.Elapsed.TotalMilliseconds.ToString("F3") + " ms";
    }

    private void CreateSpline(int index)
    {
        int controlPointCount = Random.Range(Mathf.Max(2, minControlPoints), Mathf.Max(2, maxControlPoints) + 1);
        float targetLength = Random.Range(minLength, maxLength);

        knots.Clear();

        for (int i = 0; i < controlPointCount; i++)
        {
            float time = (float)i / (controlPointCount - 1);

            float3 anchor = new float3(0f, 0f,targetLength * time);

            if (useOneSplineContainer)
                anchor.x = index * spacing;

            float3 tangentIn = new float3(0f, 0f, -1f);
            float3 tangentOut = new float3(0f, 0f, 1f);
            BezierKnot knot = new BezierKnot(anchor, tangentIn, tangentOut);

            knots.Add(knot);
        }

        if (useOneSplineContainer)
        {
            Spline spline = splineContainer.AddSpline();
            spline.Knots = knots;
            spline.Warmup();
        }
        else
        {
            GameObject go = new GameObject("Spline " + index);
            go.transform.position = transform.position + Vector3.right * index * spacing;

            SplineContainer sc = go.AddComponent<SplineContainer>();
            Spline spline = sc.AddSpline();
            spline.Knots = knots;
            spline.Warmup();
        }
    }

    private void OnGUI()
    {
        if (resultStyle == null)
        {
            resultStyle = new GUIStyle(GUI.skin.box);
            resultStyle.fontSize = 20;
            resultStyle.alignment = TextAnchor.MiddleCenter;
            resultStyle.normal.textColor = Color.white;
        }

        float width = 225f;
        float height = 75f;
        Rect rect = new Rect(465, 5, width, height);
        GUI.Box(rect, resultText, resultStyle);
    }
```
